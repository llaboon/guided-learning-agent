# Paired effects

`paired_effects.json` contains a design-aware reanalysis of the final linear-domain v2.4 results. Each comparison uses the shared profile-seed block as the unit, exact sign-flip randomization for the paired difference, and a percentile bootstrap over blocks. The values are derived from the two v2.4 result files listed in the JSON. The seed-4/5 extension was added after the initial learner-model contrast and is described as exploratory in the manuscript.
