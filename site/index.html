Guided Learning Agent

A tutoring agent for children who cannot say what they want to learn. It probes what the child knows, plans by prerequisites, teaches, and verifies, one short turn at a time.

1.67skills mastered per session by GLA, vs 0.13 for a prompt given the same curriculum
0.6%of GLA teaching turns leak the answer, vs 8.4% for that prompt
120paired sessions, 8 tutor conditions, 3 child profiles, 5 seeds
Simulated children only. Results describe agent behavior under a declared learning model.

Reproduce

Three levels, from a one-minute CPU check to a full rerun with the paper's models.

1

Offline checks

No model or GPU. Validates the simulator, interfaces and a mock run of every condition.

git clone REPO
cd gla
python -m pip install -r requirements.txt
python experiments/validate_state.py
python scripts/check_interfaces.py
python experiments/dryrun_mock.py
2

Recompute the tables

CPU only, from the released traces. Output matches the files in results/resub/analysis/.

bash scripts/analyze_resub.sh
python experiments/analyze_paired.py results/resub/main/experiment_*.json --brief
3

Rerun with models

OpenAI-compatible endpoints; the paper used vLLM 0.30.0.

# Qwen3.5-35B-A3B tutor/judge, Qwen3.5-0.8B child, Gemma-4-31B cross-family
export QWEN_URL=http://localhost:8101/v1
export CHILD_URL=http://localhost:8102/v1
export XFAM_URL=http://localhost:8103/v1
bash scripts/run_resubmission.sh main
bash scripts/run_resubmission.sh validated

Full launch commands and tolerances: REPRODUCE.md.
