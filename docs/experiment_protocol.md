# GLA 实验协议（预注册式 v0.3.3）

v0.1 由 Session-A 起草；v0.2 由 Session-B 于 2026-08-31 晚合并修订（COORDINATION.md §5）；v0.3 同晚恢复 v0.1 连续学习规则（COORDINATION.md §6，理由见 §3）。v0.3.2 于 2026-09-01 依据 v2.2 结果修订诊断放行与规划证据通道（COORDINATION.md §8，理由见 §4）；v0.3.3 同日增补泄露停摆修正与 α 敏感性开关（COORDINATION.md §9）。修改需在 git/COORDINATION.md 留痕。目标会议：AIED / AAAI-EAAI / ACL（教育 NLP track）。

## 1. 研究问题与假设

**RQ1**：对无法自述学习目标的低能力学习者（模拟幼儿），闭环式主动引导（诊断→学习者建模→课程规划→脚手架执行）相比被动响应式 LLM 导师，能否显著提高学习增益？

**RQ2**：闭环中各组件（诊断/学习者模型、课程规划器）各自贡献多少（消融）？

**RQ3**：主动引导是否同时降低教学过程缺陷（超纲教学、答案泄露、语言不适配）？

- H1：完整 GLA（C4）学习增益 > 苏格拉底 prompt（C1）> 原生 LLM（C0）。
- H2：去掉学习者模型（C2）或去掉规划器（C3）都会显著降低增益；先修违规（教被门控阻断的技能）C4 < C3。
- H3：C4 的答案泄露率不高于 C0/C1（beggar 对抗画像下重点考察）。

## 3. 模拟学习者（v2：真值状态 + 仅渲染 LLM）[v0.2 整节修订]

核心设计不变：**认知状态由程序引擎持有，LLM 只负责行为渲染**，避免"0.8B 本来就会 3+2"的先验污染（文献依据：Generative Students / BEAGLE / EduClaw-Bench，见 docs/literature_review.md 主线 E）。

- **状态**：`gla/student_state.py:GroundTruthState` 对知识图谱（`data/domains/early_math.json` v2，13 技能 DAG）每技能维护连续掌握度 m∈[0,1]（mastered ⇔ m≥0.8）。[v0.3] 恢复 v0.1 的连续规则：v2.0 试运行发现"2 次讲解暴露→掌握"的简化规则使练习与诊断回合零价值，"按拓扑序每技能讲两遍、从不评估"的脚本策略（C2）反而支配一切闭环策略——这是台架激励缺陷而非科学结论，故在主实验前回滚到预注册的掌握学习规则。
- **学习规则（冻结，v0.1 参数）**：每导师回合按盲评标注更新目标技能：先修全部 m≥0.8 才生效，否则记 blocked、Δm=0。讲解（teach/both）Δm+=0.12；提问被孩子作答：答对 +0.25、答错但尝试 +0.08、答案被泄露后跟答 +0.04；语言不可理解 ×0.3；单回合封顶 0.30；噪声 N(0,0.02)；无教学回合零漂移。guess 从 v0.1 的 0.15 下调为 0.05（幼儿算术题瞎猜命中率低，且降低测验噪声）。
- **作答机制**：P(答对)= mastered ? 1−slip : guess（slip=0.10, guess=0.05）。抽签结果为真值；若标注给出 expected（有唯一标准答案的提问），孩子话语由**模板程序合成**（正确=标准答案+孩子语气；错误=邻数/复读操作数/瞎猜/说不知道），绕开渲染 LLM——v1 实测弱 LLM 会"纠正"被指令的错误答案（服从率仅 37.5%）。开放式回合才由 0.8B 按指令渲染。答案被泄露的提问 → 孩子鹦鹉学舌（判对但不构成暴露学习）。
- **画像**（`experiments/run_experiment.py`）：zero（零基础）、mid（已会 3 个入门技能）、beggar（高频撒娇讨答案的对抗画像，beg_for_answer=0.4）；注意力参数控制走神率。
- **反循环论证声明**：学习规则只奖励"先修满足、语言可理解、以讲解为载体"的普适教学法（Mastery Learning/ZPD 可溯源），不引用任何 GLA 内部信号；基线条件同样可以（碰巧或凭 prompt）满足。规则与参数在主实验前冻结于本文件。

## 4. 对照条件（导师侧）

| 条件 | 实现名 [v0.2] | 诊断 | 学习者模型 | 课程规划 | 教学执行 |
|---|---|---|---|---|---|
| C0 原生 | vanilla | ✗ | ✗ | ✗ | "你是老师，教孩子 10 以内数学" |
| C1 苏格拉底 prompt | socratic | ✗ | ✗ | ✗ | 强教学法 prompt（引导式、不给答案、幼儿语言） |
| C2 GLA−学习者模型 | gla_fixed | ✗ | ✗ | 固定顺序过 KG | 同 C4 执行器 |
| C3 GLA−规划器 | gla_reactive | ✓ | ✓ | ✗（贪心选信念最弱技能，无先修推理） | 同 C4 执行器 |
| C4 完整 GLA | gla_full | ✓ | ✓ | ZPD 内动态选点 + 掌握推进 | 脚手架执行器 |

[v0.3.1] C4 曾引入单次探测快速放行（答对即权重 2 越过掌握线）；C3 信念平局改为随机打破（否则字典序平局恰好复刻拓扑课程，消融失真）。

[v0.3.2] v2.2 结果证伪了 v0.3.1 中「误放行可由后续练习纠回」的假设：放行后规划器不再回访该技能，不产生任何纠错证据；且真实状态的先修门槛（m≥0.8）会封死其全部下游技能的学习（zero-s1 轨迹：第 0 回合 5% 瞎蒙命中→ 其余 23 回合全部 blocked_prereq，习得 0）。修订三条，均为机制级、各条件统一适用：
1. 双探测确认（planner）：连续 2 次探测通过才放行（假放行率由 guess 5% 降至 0.25%，真会技能成本 2 回合仍远低于完整教学循环）；单次答对后一次答错即回到教学循环。无有效证据的探测最多 4 次，之后直接转教学（防执行器跑偏时空转，v2.2 zero-s1 曾连烧 10 回合诊断指令）。
2. 证据卫生（session）：规划器只接受「判裁标注技能=指令技能、非泄露、且来自模板抽签」的作答证据。废除 judge 对渲染文本评分的兜底通道——v2.2 beggar-s2 轨迹显示「示范+提问」回合的示范内容会污染渲染答案，judge 判「对」造成连续 3 次假放行；泄露回合鹦鹉学舌按构造必对，同样排除。
3. 换题提示（executor）：指令切换目标技能时显式要求收尾旧话题，抑制对话惯性拖拽（v2.2 中孩子数数的惯性使执行器连续 10 回合无视新指令）。

[v0.3.3] v2.3 结果（见 §7 附注）：H1 显著增强（C4 vs C0 +0.214, p=4e-4），规划器消融分离（C4 vs C3 +0.166, p=0.0064）。残余缺陷：数数类练习中执行器边示范边提问被判泄露，泄露回合按 v0.3.2 规则不产证据，若该技能恰为唯一 ZPD 候选则信念冻结、规划器停摆（mid-s2：24 回合 0 覆盖）。修正：泄露/未作答但含示范（act∈{teach,both}）的指令内回合触发 taught_boost（+0.5 伪计数），4 个无信息示范回合即越过掌握线——停摆有界，且方向与真实状态的 teach 增量一致，单回合不可能越线（不复活 v0.3.2 废除的污染通道）。另实现协议 §9 的 --alpha-scale 开关（0.5×/2× 学习率敏感性，仅跑 C0 vs C4）。

所有条件同一底座模型、同一温度、同一回合预算、同一标注/判分路径。

## 5. 流程与规模 [v0.2 修订]

1. **前测**：按 KG 每技能抽 A 卷 1 题，真值状态抽签判分（渲染可选，评分不依赖渲染）。
2. **教学**：1 会话 × 24 回合（回合 = 导师说一次 + 孩子答一次；每回合 1 次盲评标注）。[v0.3.1] 由 20 调至 24：连续规则下神谕节奏 ≈6.3 回合/技能，20 回合叠加冷启动开销后 gla_full 在 mid 画像出现零学习地板效应。
3. **后测**：B 卷平行题，同流程。
4. 规模：**5 条件 × 3 画像 × 3 种子 = 45 run**（约 2.5–4k LLM 调用，双服务数小时内）。
5. 试点：已完成 v1 管线试点（gla_full +0.40 vs vanilla −0.10，8 回合）；v2 离线全链路演练 `experiments/dryrun_mock.py` PASS。

## 6. 指标 [v0.2 修订]

- **主指标**：KC 级归一化学习增益 norm_gain=(post−pre)/(1−pre)，仅在**预设知识缺口**（初始未掌握技能）上计算。
- **确证性次指标**：n_learned（状态真值新增 mastered 数，无测量噪声）。
- **过程指标**：gap_coverage（触及的缺口技能/全部缺口——"主动触达"指标）、答案泄露率（leaked/实质回合）、chitchat 率、blocked（超纲被门控）事件数。
- 统计：条件间两侧置换检验（20k 次，主对照 gla_full vs 各条件的 norm_gain）+ 均值±SD 报告；无 scipy 依赖。
- 教学质量 rubric 盲评 + 人工抽检：论文阶段对抽样回合补充（MRBench 风格 8 维）。

## 9. 风险与备选

- 0.8B 渲染不稳 → 内容关键回合已模板化（不受影响）；开放回合可换 Qwen3.5-4B。
- 标注器与导师同源偏差 → 标注 prompt 盲评 + 论文阶段人工抽检 κ；必要时起 122B @ :8103 异源复标。
- 学习规则敏感性 → 备选：α∈{0.5×,1×,2×} 三档重跑主对照（C0 vs C4）验证方向稳健。
- 思维链混入 content → 已解决（chat_template_kwargs.enable_thinking=false + strip_think）。
